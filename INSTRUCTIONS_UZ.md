# uztove – Oddiy qo‘llanma (dasturlash bilmaydiganlar uchun)

## Nima qilishingiz kerak?

1. **NewPipe ni fork qiling**
   - Telefon yoki kompyuterda https://github.com/TeamNewPipe/NewPipe oching
   - Yuqoridagi **Fork** tugmasini bosing
   - O‘z akkauntingizga nusxa oling

2. **Ushbu ZIP dagi fayllarni qo‘shing**
   - ZIP ni oching
   - `.github` papkasini butunlay fork qilingan repoga yuklang
   - `scripts` va `patches` papkalarini ham yuklang

   GitHub saytida:
   - Fork qilingan repoga kiring
   - **Add file → Upload files**
   - Kerakli fayllarni sudrab tashlang
   - **Commit changes** bosing

3. **APK quring**
   - Fork qilingan repoda **Actions** bo‘limiga o‘ting
   - Chapda **Build uztove APK** ni tanlang
   - O‘ngda **Run workflow** → yana **Run workflow** bosing
   - 5–15 daqiqa kuting
   - Tugagach **uztove-debug-apk** degan faylni yuklab oling

4. **Telefonga o‘rnating**
   - APK ni oching
   - “Noma’lum manbalar” ga ruxsat bering
   - O‘rnating

## Ilova nomi
Qurilgan APK da ilova nomi **uztove** bo‘ladi.

## Muhim
- Bu NewPipe asosidagi mustaqil versiya.
- YouTube yoki original NewPipe bilan paket nomi to‘qnashmasligi uchun `uz.tove.app` ishlatiladi (imkon qadar).
- TalkBack tuzatishlari avtomatik qo‘llanadi.

Muvaffaqiyat!
